Testing prerelease for Android, Windows and Apple Silicon Mac. The stable release and automatic update channel remain on 1.2.14 while testing continues.

- Windows installs to **C:\Program Files\SyncDows** by default and includes **Uninstall-SyncDows.ps1**. Setup and uninstall write diagnostic logs; uninstall preserves mesh data and synced folders.
- Windows and Mac accept pasted pairing codes and Enter to join. Expired codes disappear with instructions to generate a replacement.
- Android pairing shows progress, prevents duplicate attempts, handles discovery timeouts, and correctly clears an erased code.
- The Sync screen offers clearer first-run setup actions. Desktop folder creation explains when mesh setup is required.
- Android Back navigation works through settings and folder browsing. Desktop device menus are visible, and narrow windows and enlarged text remain usable.
- Mac mesh diagrams show full device names and readable status labels.

**Windows upgrade:** if an older per-user installation is detected, setup preserves its legacy data and asks you to uninstall that version before installing the machine-wide version. Quit SyncDows from the system tray before uninstalling. Keep your existing synced folders.

**Please test:** fresh installation; upgrading and retaining mesh membership; pairing between platforms; adding a folder and transferring files; chat; closing and reopening the app; and Windows uninstall/reinstall. For Windows installation problems, run the EXE with `/log "%TEMP%\SyncDows-install.log"` and retain the related setup logs.

Includes the Android APK, Apple Silicon DMG, Windows x64 EXE, standalone Windows uninstall script, and signed offline bundle. Install these files manually for testing. Stable promotion will follow testing confirmation.

Real-device sync, OS integrations and Google Drive/OneDrive sign-in still need testing. Mac's Leave mesh and global overwrite-only exception controls are not included in this version.
