Sync reliability, data-safety and cloud security fixes for Android, Windows and Mac.

- Fix the “Sync needs attention” alert Android showed after syncing with a Mac or Windows PC. Devices that connect to each other at the same moment now settle on one connection and retry, instead of reporting a failed sync.
- Keep syncing after a device is removed from the mesh. Previously, removing a device that had sent chat messages or shared folders stopped every later sync and blocked new pairings.
- Sync very large folders and files over 7.8 GiB without exceeding the connection’s message limit. Stalled Android connections now time out and reconnect.
- Recovering a file from history no longer overwrites a newer version saved since the last scan, and an Android folder scan running while files arrive no longer reverts them on other devices.
- Stop syncing interrupted-transfer temporary files and Finder’s `.DS_Store`, and clean up partial downloads that stopped arriving.
- Filename capitalization clashes, and names Windows or Android storage cannot keep, become per-file conflicts instead of stopping the whole sync. Capitalization-only renames now apply on Mac and Windows.
- Mac and Windows keep syncing other folders when one folder or drive is unavailable. Deleting a file from this device only, through **Manage files**, no longer stops other devices syncing with it.
- Encrypt large cloud files in chunks so they no longer exhaust memory, and sign cloud changes with the publishing device’s identity so removed devices cannot forge them. Desktop cloud sign-in is more reliable, and Google Drive supports a configured client secret.
- Mac: resolve file conflicts in Settings → **File conflicts** by keeping this Mac’s copy, the other device’s, or both, as on Windows. SyncTosh also detects the Wi-Fi network on macOS 14.4 and later, and updates never replace it while it is still running.
- Fix update sharing when a release lacks one platform, prerelease version ordering, and Android sync status updates overwriting each other.

**Compatibility:** Update every participating device. Cloud changes are now signed, so devices only exchange them through the cloud once all run 1.2.14, and older versions cannot open cloud files of 16 MiB or more uploaded by this version.

Includes the Android APK, Apple Silicon Mac DMG, Windows x64 installer, and signed offline update bundle.
